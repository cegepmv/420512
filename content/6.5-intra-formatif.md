## Sujet d'Examen Formatif : "VinylVault - Gestion de Discothèque"

![intra1](/420512/images/intra1.png)


À partir de la **capture d'écran du produit fini** ci-dessus, tu dois développer l'application mobile correspondante en **React Native**. L'objectif est de recréer fidèlement l'interface et la logique permettant de gérer une collection personnelle de vinyles, incluant l'ajout, la modification et la suppression d'albums selon des règles précises.

---

### 🛠️ Spécifications techniques et fonctionnelles

#### 1. Données fixes imposées

L'application doit obligatoirement utiliser les données de référence suivantes :

🎶

* **Genres musicaux disponibles :** `["Rock", "Jazz", "Électro", "Hip-Hop", "Pop"]`
* **Correspondance des couleurs par genre :**
* Rock : `#D32F2F`
* Jazz : `#7B1FA2`
* Électro : `#0288D1`
* Hip-Hop : `#F57C00`
* Pop : `#C2185B`



#### 2. Le Formulaire d'Ajout et d'Édition

* **Champ de texte :** Un champ permettant de saisir le titre de l'album.
* **Sélecteur de genre :** Une liste visuelle des genres musicaux fixes mentionnés ci-dessus. 
* **Bouton d'action dynamique :**
* Par défaut, le bouton permet **d'ajouter** l'album à la collection.
* Si l'utilisateur clique sur le bouton "Modifier" d'un album de la liste, ses informations doivent remonter dans le formulaire, et le bouton d'action doit basculer en mode **"Enregistrer les modifications"**.



#### 3. Règles de Validation et Gestion des Erreurs

* **Champ vide :** Si l'utilisateur tente d'ajouter ou de modifier un album sans avoir saisi de titre, un message d'erreur explicite doit s'afficher.
* **Limite maximale :** La collection est limitée à **10 albums maximum**. Si l'utilisateur tente d'ajouter un nouvel album alors que la limite est atteinte, l'action est bloquée et un message d'avertissement s'affiche (cette limite ne s'applique pas lors de la modification d'un album existant).

#### 4. Affichage et Interactions de la Liste

* **Compteur dynamique :** Afficher en temps réel le nombre d'albums dans la collection (ex: *Collection (3 / 10)*).
* **Cartes d'albums :** Chaque album s'affiche sous forme de carte dont la couleur de fond correspond au code couleur de son genre musical.
* **Actions par carte :** Chaque élément de la liste dispose de deux boutons :
* Un bouton **"Modifier"** pour charger ses données dans le formulaire.
* Un bouton **"Retirer"** pour supprimer l'album de la collection. *(Note : si l'album en cours de modification est supprimé, le formulaire doit être réinitialisé).*

import React, { useState } from 'react';
import { StyleSheet, Text, View, TextInput, TouchableOpacity, ScrollView } from 'react-native';
import { SafeAreaView } from 'react-native-safe-area-context';

const GENRES_DISPONIBLES = ["Rock", "Jazz", "Électro", "Hip-Hop", "Pop"];

const GENRE_COLORS = {
  Rock: "#D32F2F",
  Jazz: "#7B1FA2",
  Électro: "#0288D1",
  "Hip-Hop": "#F57C00",
  Pop: "#C2185B"
};

export default function VinylVault() {
  // States de base
  const [titreAlbum, setTitreAlbum] = useState("");
  const [genreSelectionne, setGenreSelectionne] = useState("Rock");
  const [collection, setCollection] = useState([]);
  const [errorMessage, setErrorMessage] = useState("");

  // NOUVEAU: State pour stocker l'ID de l'album en cours de modification (null si on est en mode "Ajout")
  const [idEnCoursDeModification, setIdEnCoursDeModification] = useState(null);

  const handleEnregistrer = () => {
    // 1. Vérifier si le titre est vide
    if (!titreAlbum.trim()) {
      setErrorMessage("Veuillez saisir un titre d'album !");
      return;
    }

    // 2. Si on est en mode AJOUT, vérifier la limite des 10 albums
    if (idEnCoursDeModification === null && collection.length >= 10) {
      setErrorMessage("La discothèque est pleine (max 10 albums) !");
      return;
    }

    if (idEnCoursDeModification !== null) {
      // --- MODE MODIFICATION ---
      // On met à jour l'élément existant dans la collection
      const collectionMiseAJour = collection.map((album) => {
        if (album.id === idEnCoursDeModification) {
          return { ...album, titre: titreAlbum, genre: genreSelectionne };
        }
        return album;
      });
      setCollection(collectionMiseAJour);
      setIdEnCoursDeModification(null); // On sort du mode modification
    } else {
      // --- MODE AJOUT ---
      const nouvelAlbum = {
        id: Date.now().toString(),
        titre: titreAlbum,
        genre: genreSelectionne
      };
      setCollection([...collection, nouvelAlbum]);
    }
    
    // 3. Réinitialiser le formulaire et nettoyer les erreurs
    setTitreAlbum("");
    setGenreSelectionne("Rock");
    setErrorMessage("");
  };

  const handleSupprimer = (id) => {
    // Si l'album qu'on supprime est celui qu'on était en train de modifier, on annule le mode édition
    if (idEnCoursDeModification === id) {
      setIdEnCoursDeModification(null);
      setTitreAlbum("");
      setGenreSelectionne("Rock");
    }
    setCollection(collection.filter(album => album.id !== id));
  };

  const handlePreparerModification = (album) => {
    // Charger les informations de l'album dans le formulaire
    setTitreAlbum(album.titre);
    setGenreSelectionne(album.genre);
    // Mémoriser l'ID de l'album qu'on modifie
    setIdEnCoursDeModification(album.id);
    setErrorMessage("");
  };

  return (
    <SafeAreaView style={styles.container}>
      <ScrollView>
        <Text style={styles.titre}>🎶 VinylVault - Ma Discothèque 💿</Text>

        {/* Section Formulaire */}
        <View style={styles.formContainer}>
          <Text style={styles.label}>
            {idEnCoursDeModification !== null ? "Modifier l'album" : "Titre de l'album"}
          </Text>
          <TextInput
            style={styles.input}
            placeholder="Ex: Discovery - Daft Punk"
            placeholderTextColor="#666"
            value={titreAlbum}
            onChangeText={setTitreAlbum}
          />

          <Text style={styles.label}>Genre musical</Text>
          <View style={styles.genresContainer}>
            {GENRES_DISPONIBLES.map((genre, index) => {
              const isSelected = genreSelectionne === genre;
              return (
                <TouchableOpacity
                  key={`genre-${index}`}
                  style={[
                    styles.btnGenre,
                    isSelected && { backgroundColor: GENRE_COLORS[genre], borderColor: "#fff" }
                  ]}
                  onPress={() => setGenreSelectionne(genre)}
                >
                  <Text style={styles.textBtnGenre}>{genre}</Text>
                </TouchableOpacity>
              );
            })}
          </View>

          {/* Le bouton change de couleur et de texte selon qu'on ajoute ou qu'on modifie */}
          <TouchableOpacity 
            style={[
              styles.btnAction, 
              idEnCoursDeModification !== null ? styles.btnModeModif : styles.btnModeAjout
            ]} 
            onPress={handleEnregistrer}
          >
            <Text style={styles.textBtnAction}>
              {idEnCoursDeModification !== null ? "Enregistrer les modifications" : "Ajouter à la collection"}
            </Text>
          </TouchableOpacity>

          {errorMessage ? <Text style={styles.error}>{errorMessage}</Text> : null}
        </View>

        {/* Section Liste de la collection */}
        <Text style={styles.sousTitre}>
          Collection ({collection.length} / 10)
        </Text>

        <View>
          {collection.map((album) => {
            const couleurFond = GENRE_COLORS[album.genre] || "#333";
            return (
              <View key={album.id} style={[styles.cardAlbum, { backgroundColor: couleurFond }]}>
                <View style={styles.infoAlbum}>
                  <Text style={styles.textCardTitre}>{album.titre}</Text>
                  <Text style={styles.textCardGenre}>{album.genre}</Text>
                </View>

                {/* Conteneur des boutons Modifier et Retirer */}
                <View style={styles.actionsContainer}>
                  <TouchableOpacity 
                    style={styles.btnModifier} 
                    onPress={() => handlePreparerModification(album)}
                  >
                    <Text style={styles.textBtnActionCard}>Modifier</Text>
                  </TouchableOpacity>

                  <TouchableOpacity 
                    style={styles.btnSupprimer} 
                    onPress={() => handleSupprimer(album.id)}
                  >
                    <Text style={styles.textBtnActionCard}>Retirer</Text>
                  </TouchableOpacity>
                </View>
              </View>
            );
          })}
        </View>
      </ScrollView>
    </SafeAreaView>
  );
}

import { StyleSheet, Text, View, TextInput, TouchableOpacity, ScrollView} from 'react-native'

const GENRE = ["Rock", "Jazz", "Électro", "Hip-Hop", "Pop"]
const COULEUR_PAR_GENRE = {
 "Rock" : `#D32F2F`,
 "Jazz" : `#7B1FA2`,
 "Électro" : `#0288D1`,
 "Hip-Hop" : `#F57C00`,
 "Pop" : `#C2185B`
}
const VinylVault = () => {
  const [collection, setCollection] = useState([])
  const [genreActif, setGenreActif] = useState(null)
  const [formValue, setFormValue] = useState("")
  const [modeModif, setModeModif] = useState(false)
  const oldData = useRef({})
  const handleClickGenre = (genre) => {
    setGenreActif(genre)
  }
  const handleClickAJout = () => {
    if (formValue != "" && genreActif != null) {
      setCollection((prev) => [...prev, {"description": formValue, "genre": genreActif}])
      setFormValue("")
    }
    else {
      alert("Vous devez entrer le nom et un genre")
    }
  }
  const handleClickModif = (data) => {
    setFormValue(data.description)
    setGenreActif(data.genre)
    oldData.current = data
    setModeModif(true)
  }
  const handleClickSaveModif = () => {
    setCollection((prev) => [...prev.filter((t) => !(t.description == oldData.current.description && t.genre == oldData.current.genre)), {"description": formValue, "genre": genreActif}])
    setModeModif(false)
  }
  const handleClickRetirer = (data) => {
    setCollection((prev) => prev.filter((t) => !(t.description == data.description && t.genre == data.genre)))
  }
  return (
    <SafeAreaView style={styles.container}>
      <Text style={styles.title}>🎶VinylVault - Ma Discothèque</Text>
      <View style={styles.form}>
        <Text style={styles.labelForm}>{"Titre de l'album"}</Text>
        <TextInput 
          style={styles.input} 
          placeholderTextColor={"#676363b2"} 
          placeholder='Ex: Discovery - Daft Punk'
          value={formValue}
          onChangeText={(text) => setFormValue(text)}/>
        <Text style={styles.labelForm}> Genre musical</Text>
        <View style={styles.containerGenre}>
          {GENRE.map((genre, index) => {
            const isActive = genreActif == genre
            return (
              <TouchableOpacity key={index} onPress={() => handleClickGenre(genre)} style={[styles.btnGenre, isActive && {backgroundColor: COULEUR_PAR_GENRE[genre]}]}>
                <Text style={styles.textGenre}>{genre}</Text>
              </TouchableOpacity>

          )})}
        </View>
        {}
        <TouchableOpacity onPress={modeModif ? handleClickSaveModif : handleClickAJout} style={styles.btnAjouterCollection}>
          <Text style={styles.textBtnAjouterCollection}>{modeModif ? "Modifier l'entrée" : "Ajouter à la collection"}</Text>
        </TouchableOpacity>
      </View>
      <Text style={styles.titleCollection}>Collection (1/10)</Text>
      <ScrollView style={styles.scroll}>
        {collection.map((data, index) => {
          return (
                  <View key={index} style={[styles.card, {backgroundColor:COULEUR_PAR_GENRE[data.genre]}]}>
                    <View style={styles.cardLeft}>
                      <Text style={styles.titleSong}>{data.description}</Text>
                      <Text style={styles.typeSong}>{data.genre}</Text>
                    </View>
                    <View style={styles.cardRight}>
                      <TouchableOpacity onPress={() => handleClickModif(data)} style={[styles.btnCollection, {backgroundColor: "#fb783b"}]}>
                        <Text style={styles.textBtnCollection}>Modifier</Text>
                      </TouchableOpacity>
                      <TouchableOpacity onPress={() => handleClickRetirer(data)} style={[styles.btnCollection, {backgroundColor: "#bc4610"}]}>
                        <Text style={styles.textBtnCollection}>Retirer</Text>
                      </TouchableOpacity>
                    </View>
                  </View>

          )
        })}
      </ScrollView>
    </SafeAreaView>
  )
}
